# yo-jorney-builder

Десктопна програма (Python + Eel) для підготовки товарних фото: пошук і завантаження фото за артикулами з Excel, підготовка PNG та генерація обкладинок 810×853.

## Запуск

**Готовий exe:** завантажте `YoJourneyBuilder.exe` з [Releases](https://github.com/Saymoregeomancer/yo-jorney-builder/releases) і запустіть. Встановлювати Python не потрібно. Вікно відкривається через Microsoft Edge, який є в Windows 10/11.

**З вихідного коду:**

```bat
pip install -r requirements.txt
python main.py
```

**Збірка exe:** `build.bat` → `dist\YoJourneyBuilder.exe`

## Структура папок

Коли ви вибираєте Основну директорію, програма створює в ній такі папки:

```
Основна директорія/
├── downloaded-images/   Step 3: завантажені фото (підпапка на кожен артикул)
├── png/                 вирізані PNG одягу, з них робляться обкладинки одягу
├── png_shoes/           PNG взуття, з них робляться обкладинки взуття
├── png_bc/              використані PNG (переміщуються сюди після генерації), джерело для дитячих обкладинок
├── обкладинки/          готові JPG
├── _backups/            бекапи (Excel + png_bc)
├── child_shoes.txt      список дитячого взуття
└── not_found.txt        не знайдені артикули
```

Програма запам'ятовує Основну директорію, шлях до Excel, API ключ, регіон, проксі й тему. Налаштування лежать у `%APPDATA%\YoJourneyBuilder\config.json`.

## Можливості

- **Парсинг фото** (serper.dev): фото для артикулів з листа «Шаблон» зберігаються в `downloaded-images/`
- **Список не знайдених** і **зміна формату в JPG**: папку вибирають зі списку
- **Групування по 3**, **відзеркалення**, **перейменування** `1___КОД___...` → `КОД`
- **Виділити взуття**: вибрані PNG переміщуються з `png/` у `png_shoes/`
- **Дитяче взуття**: з листа «Шаблон» беруться рядки, де H = «Детский», а тип товару (F) входить у список типів із «Справочник», де B = «Взуття». Результат зберігається в `child_shoes.txt`
- **Обкладинки** (результат іде в `обкладинки/`, використані PNG переміщуються в `png_bc/`):
  - одяг з моделями (без відступу від краю)
  - одяг без моделей (з відступом)
  - взуття на фоні `assets/810x853_2.jpg` з авто-вирівнюванням підошви; максимальне відхилення можна змінити, за замовчуванням 12°
  - дитяче взуття: береться за списком `child_shoes.txt` з `png_bc/` і зменшується до 64% з відступом 100 px від низу
- **Бекап і очищення**: Excel і `png_bc` зберігаються в `_backups/<дата>`, а решта вмісту Основної директорії видаляється
- Світла й темна тема
